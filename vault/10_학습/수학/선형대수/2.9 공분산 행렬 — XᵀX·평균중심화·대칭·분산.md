# 공분산 행렬 — XᵀX·평균중심화·대칭·분산

> 📐 **수학 개념원자(SSoT)** — 선형대수. 공분산 행렬의 단일 주인 = **$X^{\mathsf{T}}X$ 곱셈 기법([[2.3 행렬 전치 — 내적·외적 표기법·LIVE EVIL·대칭 행렬|2.3]])의 통계적 재취업**. AI 적용·연결은 코스 렌즈가 끌어다 쓴다.
> 🔗 [[_수학 MOC]] ｜ 🌐 [[_지식 연결 허브]] ｜ 🎓 AI 렌즈: [[27 공분산 행렬 — 데이터 특징 상관구조 (화이트닝·PCA 예고)|27 공분산(AI)]] ｜ 토대: [[2.3 행렬 전치 — 내적·외적 표기법·LIVE EVIL·대칭 행렬|AᵀA 대칭]] · [[2.5 행렬 노름·대각합 — 프로베니우스·ℓ2·tr(AᵀA)|대각=자기 내적]] · [[1.9 상관관계와 코사인 유사도 — 피어슨 상관계수·평균중심화·분할정규화|피어슨=중심화+노름]]

> 🎯 **핵심 (TL;DR)**
> - **공분산 = 두 평균중심화 변수의 내적 / (n−1)** 📌 — 상관계수 공식의 **분자**($\tilde{x}^{\mathsf{T}}\tilde{y}/(n-1)$). 데이터 크기가 반영돼 **±1 제한이 없다**(상관과 유일한 차이). 해석은 상관과 동일(함께↑=양수·따로=음수·선형무관=0).
> - **공분산 행렬 = $C = X^{\mathsf{T}}X\dfrac{1}{n-1}$** 📌 — 각 변수(특징)를 **열**에 담은 데이터 행렬 $X$. $X^{\mathsf{T}}X$ 의 $(i,j)$ = 특징 $i$·$j$ 의 (중심화) 내적 = 모든 열쌍의 공분산을 **한 번에**.
> - **행렬 곱 = 왼쪽 행 × 오른쪽 열 내적들의 집합** — 이 사실이 "쌍마다 for문" 대신 한 연산으로 전 쌍을 재는 열쇠.
> - **$C$ 는 대칭** 📌 — $X^{\mathsf{T}}X$ 는 항상 정방 대칭([[2.3 행렬 전치 — 내적·외적 표기법·LIVE EVIL·대칭 행렬|2.3]] 곱셈 기법)이자 통계적으로도 $\text{cov}(x,y)=\text{cov}(y,x)$.
> - **대각 원소 = 각 변수의 자기 공분산 = 분산(variance)** 📌 — 평균 주변 흩어짐(=표준편차의 제곱). 비대각 = 쌍의 공분산.
> - **정규화 인자 n−1** (n=데이터 점 수) — 값을 많이 합할수록 커지는 걸 막음(평균 내려 나누기와 유사). ⚠️ 책은 이 표면 이유만 준다 — 왜 n이 아니라 **n−1**인가(자유도·불편추정)는 이 절 범위 밖 `(🔭 예고 — 통계 추정)`.
> - **왼쪽을 전치하는 이유 = 특징 대 특징을 만들려고** — 관측치를 열로 뒀다면 $XX^{\mathsf{T}}$. 공분산 행렬은 **항상 특징×특징**([[2.3 행렬 전치 — 내적·외적 표기법·LIVE EVIL·대칭 행렬|2.3]]의 "AᵀA≠AAᵀ" 구분이 여기서 방향 규칙으로).

> [!question] 🎯 필요성 사슬 (결핍 → 필요 → 발명)
> *출발 문제:* 변수가 3개 이상(키·몸무게·나이·운동…)일 때 **모든 쌍의 관계**를 이중 for문 없이 한 번에 재고 싶다 — 쌍마다 이변량 공식을 도는 건 선형대수 철학에 안 맞는다.
> 1. 두 변수 상관은 내적을 노름 곱으로 나눈 것([[1.9 상관관계와 코사인 유사도 — 피어슨 상관계수·평균중심화·분할정규화|1.9]]) — 변수가 많아지면 쌍마다 반복 → **한 연산으로 전 쌍을** → 행렬로
> 2. 각 변수를 **열**에 담은 $X$ — 행렬 곱은 "왼쪽 행 × 오른쪽 열 내적들의 집합"이므로 $X^{\mathsf{T}}X$ 가 **모든 열쌍의 내적**을 동시 생산([[2.3 행렬 전치 — 내적·외적 표기법·LIVE EVIL·대칭 행렬|2.3]] 곱셈 기법)
> 3. 크기(스케일)를 반영한 채 재려면 = **공분산**(평균중심화 내적, ±1 제한 없음) → 값 폭주 막게 **n−1로 정규화**
> 4. 자기 자신과의 공분산 = **분산**(대각), 쌍의 공분산 = 비대각 → 대칭 행렬 하나에 전부
> **한 줄:** 모든 특징 쌍의 평균중심화 내적을 한 번에 = $X^{\mathsf{T}}X/(n-1)$ — 대각은 분산, 비대각은 공분산, 전체는 대칭.

> [!abstract] 📘 책 핵심 — [실전선대] 6장 도입 · §6.1 다변량 데이터 공분산 행렬
> **① 6장 도입 — 행렬 응용**
> - 4·5장(행렬 이론) 뒤, 6장은 3장 **벡터 응용을 행렬로** 잇는 장. 기반은 여전히 **선형 가중 결합 + 내적**이라는 간단한 원칙.
>
> **② §6.1 — 공분산부터**
> - **공분산 = 상관계수 공식의 분자** = 두 평균중심화된 변수의 내적. 데이터 크기 반영 → **±1 제한 없음**. 해석은 상관과 같음(양수=함께 이동·음수=따로·0=선형 무관).
> - **정규화 인자 = n−1** (n=데이터 점 개수). 많이 합할수록 커지는 것 방지(합에서 평균 구하려 나누기와 유사).
> - 공분산 방정식:
> $$ c_{a,b}=(n-1)^{-1}\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\bar{y}) $$
> - $\tilde{x}$=평균중심화된 $x$ 라 하면 공분산 $=\tilde{x}^{\mathsf{T}}\tilde{y}/(n-1)$ ([[1.9 상관관계와 코사인 유사도 — 피어슨 상관계수·평균중심화·분할정규화|1.9]] 표기 그대로).
> - **다중 변수:** 행렬 곱 = 왼쪽 행렬 행과 오른쪽 행렬 열의 **내적들의 집합**이라는 사실을 이용. 각 변수를 **열**에 담은 $X$ 생성(변수=특징=열). $XX$ 는 의미 없음(데이터는 보통 $M{>}N$ 이라 성립도 안 함). 첫 행렬을 전치하면 $X^{\mathsf{T}}$ 의 **행**=$X$ 의 **열** → $X^{\mathsf{T}}X$ = 모든 열쌍의 공분산(열 중심화 가정, n−1로 나눔).
> - 공분산 행렬 방정식: $ C=X^{\mathsf{T}}X\dfrac{1}{n-1} $
> - **$C$ 는 대칭**(4장 "$A^{\mathsf{T}}A$ 는 정방 대칭" 증명 + 통계적으로도 대칭 — 키↔체중 상관 = 체중↔키 상관).
> - **$C$ 의 대각 = 각 변수의 자기 공분산 = 분산(variance)** — 평균 주변 흩어진 정도(분산=표준편차 제곱).
>
> **③ 콜아웃 — 왜 왼쪽을 전치하나?**
> - 특별한 이유 없음. 관측치를 열·특징을 행으로 뒀다면 $XX^{\mathsf{T}}$. 헷갈리면 **특징×특징 행렬이 나오는지**로 판단. 공분산 행렬은 항상 특징 대 특징.

## 🧠 근본 이해 · 융합 · 통찰

### 🔑 공분산 행렬 = "AᵀA 곱셈 기법"의 통계적 재취업 (2.3 회수)
- [[2.3 행렬 전치 — 내적·외적 표기법·LIVE EVIL·대칭 행렬|2.3]]에서 "**어떤 행렬이든 $A^{\mathsf{T}}A$ 는 정방 대칭**"이 순수 대수 사실이었다. 그 $A$ 에 **평균중심화된 데이터 행렬 $X$** 를 넣으면 $X^{\mathsf{T}}X$ 가 곧 (스케일 전) 공분산 행렬 — 대수 도구가 통계 대상으로 옷을 갈아입는 정확한 지점.
- 노트 22([[22 확률·통계 용어 지도 — 확률 변수·분포·기대값·공분산·마르코프|22]])가 예고했던 "선형대수 원자들이 확률로 재취업하는 현장"의 실체가 이 절이다: **대칭**은 2.3, **대각=자기 성분**은 2.5, **상관=정규화된 공분산**은 1.9 — 세 원자가 한 행렬에서 만난다.
- 📌 $(i,j)$ 원소의 정체 = **특징 $i$ 열과 특징 $j$ 열의 (중심화) 내적**. 행렬 곱의 정의(행×열 내적)를 그대로 읽으면 공분산 행렬의 의미가 저절로 나온다 — 외울 게 아니라 **읽는 것**.

### 🔑 대각 = 분산 — 2.5의 "AᵀA 대각 = 열의 자기 내적"이 여기선 variance가 된다
- [[2.5 행렬 노름·대각합 — 프로베니우스·ℓ2·tr(AᵀA)|2.5]]에서 $\lVert A\rVert_F=\sqrt{tr(A^{\mathsf{T}}A)}$ 를 풀며 "$A^{\mathsf{T}}A$ 의 대각 $(i,i)$ = 그 **열의 자기 내적**(제곱합)"임을 봤다. 데이터 행렬에선 그 "열의 제곱합"이 곧 **중심화된 값의 제곱합** → $/(n-1)$ 하면 **분산**.
- 즉 프로베니우스에서 "버리는 계산"(비대각 만들고 대각만 씀)이라 했던 그 대각이, 통계에선 **주인공(분산)**이 된다. 같은 $A^{\mathsf{T}}A$ 대각선을 노름은 에너지로, 통계는 흩어짐(분산)으로 읽는다.
- 자기 자신과의 공분산이 분산이라는 건 정의상 당연: $\text{cov}(x,x)=\tilde{x}^{\mathsf{T}}\tilde{x}/(n-1)=\text{var}(x)$.

### 🔑 공분산 → 상관 = 노름 나누기 한 단계 (1.9 회수, 두 정규화 구분)
- [[1.9 상관관계와 코사인 유사도 — 피어슨 상관계수·평균중심화·분할정규화|1.9]] 피어슨 $\rho=\tilde{x}^{\mathsf{T}}\tilde{y}/(\lVert\tilde{x}\rVert\lVert\tilde{y}\rVert)$ = 평균중심화(빼기) + 노름 나눔(나누기). **공분산은 같은 분자 $\tilde{x}^{\mathsf{T}}\tilde{y}$ 를 공유하되, 노름으로 안 나누고 $n-1$ 로만** 나눈 것 → 그래서 스케일이 남고 ±1 제한이 없다.
- ⚠️ **정규화가 두 종류라 헷갈리지 말 것:** 공분산의 $n-1$ 은 **표본 크기 정규화**(값 폭주 방지), 상관의 노름 나눔은 **스케일 정규화**(단위 무관 −1~1). 공분산 행렬 → 상관 행렬 = 각 축을 표준편차로 다시 나누는 것($D^{-1}CD^{-1}$, $D$=표준편차 대각) — for문 없이 벡터 노름으로 크기 조절 `(→ 연습 6-1·6-2, 6.3 이후 범위)`.
- **독립 > 공분산 0:** 공분산·상관은 **선형** 닮음만 잰다([[20 수학 모델 — 선형·비선형·시뮬레이션과 AI 3중 관계|20]] 비선형 세상) — 비선형 의존은 공분산 0에도 숨는다. 노트 22의 "독립은 공분산 0보다 강함"이 이 이유.

### 🔑 왼쪽 전치의 방향 규칙 = "AᵀA vs AAᵀ 둘은 다르다"의 실전판
- [[2.3 행렬 전치 — 내적·외적 표기법·LIVE EVIL·대칭 행렬|2.3]]의 📌 "$A^{\mathsf{T}}A$ 와 $AA^{\mathsf{T}}$ 는 둘 다 대칭이지만 서로 다른 행렬"이 여기서 **어느 걸 쓰나**의 규칙이 된다:
  - $X^{\mathsf{T}}X$ ($N{\times}N$, 특징×특징) = **공분산 행렬** — 변수를 열에 담았을 때.
  - $XX^{\mathsf{T}}$ ($M{\times}M$, 관측치×관측치) = 관측치 사이 유사도(그람 행렬 계열) — 변수를 행에 담았을 때.
- 데이터가 보통 $M(\text{관측})\gg N(\text{특징})$ 이라 $X^{\mathsf{T}}X$ 는 작은 $N{\times}N$, $XX^{\mathsf{T}}$ 는 거대한 $M{\times}M$. 목적(특징 상관)에 맞는 방향을 고르는 것 — 책이 "특징×특징이 나오는지 생각하라"고 한 이유.

## 🧩 코드 (§6.1)
> 🎯 목표: 공식 $C=X^{\mathsf{T}}X/(n-1)$ 를 브로드캐스트 중심화 + `.T @` 로 직접 구현(책은 `np.cov()` 호출 대신 공식 구현 권장 — 메커니즘 이해).
> 코드: `~/LOCAL/03-00_STUDIES/AI/01_linear_algebra/la6_covariance.py` (예정)

```python
import numpy as np
# dataMat: (n, p) — 행=관측치 n개, 열=특징 p개
datamean = np.mean(dataMat, axis=0)      # 특징 평균 벡터 (p,) — axis=0 = 열별
dataMatM = dataMat - datamean            # 브로드캐스트 평균중앙화 (n,p)-(p,)=(n,p)
covMat = dataMatM.T @ dataMatM           # 데이터 행렬의 전치 × 데이터 행렬 = XᵀX  (p,p)
covMat /= (dataMatM.shape[0] - 1)        # N-1로 나누기 (shape[0]=행 수=관측치 n)
# 관찰 포인트: covMat 은 (p,p) 정방 대칭; 대각 = 각 특징의 분산; np.cov(dataMat.T) 와 일치
```

## 🆕 용어
| 용어 | 한 줄 정의 |
|---|---|
| **공분산** (covariance, $c_{a,b}$) | 두 평균중심화 변수의 내적$/(n-1)$; 상관계수의 **분자**; ±1 제한 없음(스케일 반영) |
| **공분산 행렬** $C=X^{\mathsf{T}}X/(n-1)$ | 특징을 열에 담은 $X$ 의 $X^{\mathsf{T}}X$ 정규화; $X^{\mathsf{T}}X$ 의 $(i,j)$=특징 $i$·$j$ 열 내적($C_{ij}$ 는 그것$/(n-1)$); 정방 대칭 |
| **분산** (variance) | 자기 자신과의 공분산 $\text{cov}(x,x)$; 공분산 행렬의 **대각**; =표준편차의 제곱 |
| **평균중심화** (mean-centering, $\tilde{x}$) | 각 값에서 그 변수 평균을 뺌; 공분산·상관·PCA의 공통 전처리(빼기) |
| **정규화 인자 n−1** | 표본 크기 정규화(합 폭주 방지); 자유도/불편추정 근거는 🔭 예고 |
| **특징 대 특징 vs 관측치 대 관측치** | $X^{\mathsf{T}}X$(N×N, 공분산) vs $XX^{\mathsf{T}}$(M×M, 관측 유사도) — 데이터 방향이 정함 |
| `np.cov()` / `np.corrcoef()` | 공분산/상관 행렬 NumPy 함수; 책은 공식 직접 구현 권장 |

| 공분산의 정체(상관과 관계)? | 상관계수 공식의 **분자** = 두 중심화 변수의 내적$/(n-1)$; 스케일 반영이라 ±1 제한 없음 |
| 공분산 행렬 공식? 📌 | $C=X^{\mathsf{T}}X\dfrac{1}{n-1}$ — 특징을 **열**에 담은 $X$ |
| $C$ 의 $(i,j)$ 원소는? | $X^{\mathsf{T}}X$ 의 $(i,j)$=특징 $i$·$j$ 열의 중심화 내적; $C_{ij}$ 는 그것$/(n-1)$ (행렬곱=행×열 내적) |
| 왜 $C$ 는 대칭? 📌 | $X^{\mathsf{T}}X$ 는 항상 정방 대칭(2.3 곱셈 기법) + 통계적 $\text{cov}(x,y)=\text{cov}(y,x)$ |
| $C$ 의 대각 원소는? 📌 | 각 변수의 자기 공분산 = **분산**(=표준편차²) |
| 왜 왼쪽을 전치? | **특징×특징**을 만들려고; 관측치를 열로 뒀다면 $XX^{\mathsf{T}}$ |
| 정규화 인자와 그 이유? | $n-1$ — 값 많이 합할수록 커지는 것 방지(책 표면 이유); 자유도는 🔭 |
| 공분산 → 상관 한 단계? | 노름으로 나눔(스케일 정규화) — 공분산은 분자만; 상관은 −1~1 |
| 독립 vs 공분산 0? 📌 | 독립이 더 강함 — 공분산은 **선형** 닮음만; 비선형 의존은 0에 숨음 |

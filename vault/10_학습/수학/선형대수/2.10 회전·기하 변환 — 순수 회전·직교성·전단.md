> 🎯 **핵심 (TL;DR)**
> - **순수 회전 행렬 = 길이를 유지하며 벡터를 회전** 📌 — 아날로그 시계 침(회전하되 길이 불변). 2×N 점 행렬에 왼쪽 곱하면 전 점을 한 번에 회전.
> - **2D 회전 행렬(실전선대):** $T=\begin{bmatrix}\cos\theta & \sin\theta \\ -\sin\theta & \cos\theta\end{bmatrix}$ 📌 — ⚠️ **이건 시계방향(CW)** = 수학 표준 반시계(CCW) 회전행렬의 **전치**. 부호 배치 헷갈리면 각 θ에 점 하나 넣어 검산.
> - **순수 회전 = 직교 행렬** 📌 — 열이 **정규직교**(서로 내적 $\cos\theta\sin\theta-\sin\theta\cos\theta=0$, 각 노름 $\sqrt{\cos^2\theta+\sin^2\theta}=1$). $\det T=\cos^2\theta+\sin^2\theta=1$(넓이·방향 보존). 직교 행렬 **이론 심화는 7장** `(🔭 예고)`.
> - **θ=0 → T=I**(불변), **θ=π/2 → 90° 회전**. 각도를 매개변수로 잡아 **애니메이션** 가능.
> - **흔들리는 원 = 애니메이션된 전단(shear)** 📌 — $T=\begin{bmatrix}1 & 1-\phi \\ 0 & 1\end{bmatrix}$ 는 회전이 아니라 **수평 전단**(대각=1 고정, 비대각 $1-\phi$ 가 기울임). $\det=1$(넓이 보존 — [[3D 변환 행렬 — 동차좌표·회전·투영 (선형대수 응용)|3D 원자]] "전단 det=1"의 실물). ⚠️ 그러나 **det=1 ≠ 직교** 📌 — $T^{\mathsf{T}}T\neq I$ 라 **길이는 보존하지 않는다**(회전은 넓이·길이 둘 다 → 여기가 전단↔회전의 결정적 갈림). $\phi=x^2,\,x\in[-1,1]$ 로 $1{\to}0{\to}1$ → 전단계수 $1-\phi$ 가 $0{\to}1{\to}0$ → 원↔기울어진 타원↔원. $\phi{=}1$이면 $T{=}I$.
> - **CGI·게임 3D 회전 = 4원수(quaternion, $\mathbb{R}^4$)** — 더 복잡하나 "좌표 행렬에 변환 행렬 곱" 원리는 동일 `(🔭 참고)`.

> - 사용: θ=회전각으로 두고 **2×N 기하학적 점 행렬**(각 열=한 점의 (X,Y))에 곱. θ=0 → 위치 불변($T{=}I$). θ=π/2 → 원점 중심 90° 회전.

> - 프레임마다 변환 행렬을 부드럽게 조정. 원 = $(\cos\theta,\sin\theta)$ 점, θ∈[0,2π].
> - 변환 행렬: $ T=\begin{bmatrix}1 & 1-\phi \\ 0 & 1\end{bmatrix} $ — 대각 원소는 x·y축 크기 조정, 비대각은 두 축을 늘림(전단). 값은 저자가 보기 깔끔할 때까지 직접 고름.

## 🧠 근본 이해 · 융합 · 통찰

### 🔑 순수 회전 = 직교 행렬 = 길이 보존 — 세 표현이 한 사실
- "길이 유지"(시계 침)와 "열이 정규직교"(직교 행렬)와 "$\det=1$"은 같은 사실의 세 얼굴이다. 열이 정규직교면 $T^{\mathsf{T}}T=I$ → 임의 $v$ 에 대해 $\lVert Tv\rVert^2=(Tv)^{\mathsf{T}}(Tv)=v^{\mathsf{T}}T^{\mathsf{T}}Tv=v^{\mathsf{T}}v=\lVert v\rVert^2$ → **노름 불변**. 시계 침의 길이가 안 변하는 이유가 이 한 줄.
- 이 노트가 **직접 보이는 것**은 여기까지(열 정규직교 → 길이 보존). "직교 행렬"이라는 대상의 **일반 이론**(역=전치, 고윳값 크기 1 등)은 책이 명시적으로 **7장으로 미룸** → 규칙17에 따라 정복 대상 아님 `(🔭 7장)`.
- $\det T=1$ 이라 [[3D 변환 행렬 — 동차좌표·회전·투영 (선형대수 응용)|3D 원자]]의 det 분류표 "+1: 회전·전단(넓이·방향 보존)" 행에 정확히 앉는다.
- ⚠️ **다만 화살표는 한쪽으로만 간다** 📌 — 정규직교 ⇒ $\det=\pm1$ 은 참이지만 **역은 거짓**이다. $\det=1$ 만으로는 직교가 보장되지 않고, 반례가 바로 이 노트 안에 있다: 전단 $\begin{bmatrix}1&1-\phi\\0&1\end{bmatrix}$ 은 $\det=1$ 인데 $T^{\mathsf{T}}T\neq I$ 다(아래 전단 절). 그러니 위 "세 얼굴"은 **순수 회전 행렬이라는 전제 아래에서** 성립하는 동치이지, "$\det=1$ 이면 회전"이라는 뜻이 아니다. $\det$ 은 넓이(부피) 배율만 말할 뿐 **길이·각에 대해서는 아무 말도 하지 않는다.**

### 🔑 실전선대 T는 시계방향(CW) — 표준 CCW의 전치 (기존 원자와 화해)
- ⚠️ **중대 표기 주의:** 실전선대 $T=\begin{bmatrix}\cos\theta&\sin\theta\\-\sin\theta&\cos\theta\end{bmatrix}$ 는 **시계방향(CW) 회전**이다. 검산: θ=π/2 → $T=\begin{bmatrix}0&1\\-1&0\end{bmatrix}$, $[1,0]^{\mathsf{T}}$ 에 적용 → $[0,-1]^{\mathsf{T}}$(점 (1,0)이 (0,−1)로 = 시계방향 90°).
- 수학 표준(반시계 CCW) 회전행렬은 $\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$ — **부호 배치가 반대**. 두 행렬은 서로 **전치** 관계($R_{CW}=R_{CCW}^{\mathsf{T}}=R_{CCW}^{-1}$, 회전은 직교라 전치=역=반대방향 회전).
- 📌 **[[3D 변환 행렬 — 동차좌표·회전·투영 (선형대수 응용)|3D 원자]]의 $R_z$ 는 표준 CCW** $\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$. **두 노트는 모순이 아니라 방향 컨벤션 차이(전치 관계)** — 실전선대는 CW, 3D 원자·수학 표준은 CCW. 회전각 부호나 sin 위치만 다름. 책 각주2가 "사인들의 빼기 기호를 맞바꾸면 반대 방향(CCW)"이라 한 것이 이 전치.

### 🔑 흔들리는 원 = 애니메이션된 전단 (3D 원자 "전단 det=1" 회수)
- 책 도입은 "가변 회전"이라 느슨히 부르지만, $T=\begin{bmatrix}1&1-\phi\\0&1\end{bmatrix}$ 는 **회전이 아니라 수평 전단(shear)** — 대각이 1로 고정이라 **축 방향 스케일링이 없고**(x축 위 점은 제자리), 비대각 $1-\phi$ 가 y에 비례해 x를 밀어 기울인다. 원에 전단을 걸면 **기울어진 타원**([그림 6-3]). ⚠️ "축 스케일링 없음"이 "길이 불변"은 아니다 — 아래 참조.
- $\det=1\cdot1-(1-\phi)\cdot0=1$ — **넓이 보존.** [[3D 변환 행렬 — 동차좌표·회전·투영 (선형대수 응용)|3D 원자]] "2D 아핀 총람"의 "전단 x/y det=1(기울어져도 밑변×높이 유지)"가 여기 애니메이션으로 살아 움직이는 것. 전단의 고유벡터도 그 도감에 있음(x축 $[1,0]^{\mathsf{T}}$, 고윳값 1) → 전 변환 도감·det·고유벡터는 3D 원자에 위임.
- ⚠️ **그 $\det=1$ 은 "회전 자격증"이 아니다** 📌 — 전단은 $T^{\mathsf{T}}T\neq I$ 라 **길이를 안 지킨다.** 최대 전단($\phi{=}0$)에서 $T=\begin{bmatrix}1&1\\0&1\end{bmatrix}$, $T^{\mathsf{T}}T=\begin{bmatrix}1&1\\1&2\end{bmatrix}\neq I$ 이고 $[0,1]^{\mathsf{T}}$ 의 상은 $[1,1]^{\mathsf{T}}$ 로 노름이 $1\to\sqrt{2}$ 가 된다. 즉 **회전 = 넓이 + 길이 보존, 전단 = 넓이만 보존.** 원이 "흔들려도 커 보이지 않는" 이유(넓이 불변)와 "찌그러져 보이는" 이유(길이 변화)가 한 행렬 안에 같이 들어 있다.
- 흔들림의 정체 = 전단계수 $1-\phi$ 가 $0{\to}1{\to}0$($\phi:1{\to}0{\to}1$). $\phi=1$(=$x=\pm1$)에서 $1-\phi=0$ → $T=I$ → 원. $\phi=0$(=$x=0$)에서 $1-\phi=1$ → 최대 전단. **넓이는 절대 안 변하고(det=1) 기울기만 오가는** 게 "흔들림".

### 🔑 변환 = 행렬 @ 점 행렬 (2.2 회수, 원점 기준)
- [[2.2 행렬 곱셈·행렬식|2.2]]에서 "행렬 = 변환, 행렬곱 = 변환 합성"을 봤다 — 여기선 그 변환을 **2×N 점 행렬 전체에 한 번에** 적용($P=T@\text{points}$): 각 열이 한 점이라 곱 한 번으로 모든 점이 변환된다(for문 불필요).
- 이 회전·전단은 전부 **원점 기준(about origin)**. 임의 점 기준 회전은 [[3D 변환 행렬 — 동차좌표·회전·투영 (선형대수 응용)|3D 원자]]의 $T_p R T_{-p}$ 합성(이동∘회전∘역이동)이 필요 — 동차좌표로 3×3 한 방에 접힘. 여기(§6.2)는 원점 기준 순수 회전·전단만.

```python
# ── 헬퍼 3개 (전문은 위 경로) ──
def rot_cw(theta):        # 실전선대 §6.2 = 시계방향(CW)
    return np.array([[ np.cos(theta), np.sin(theta)],
                     [-np.sin(theta), np.cos(theta)]])

def rot_ccw(theta):       # 수학 표준(CCW) = 각주2 '사인 부호 맞바꿈' = rot_cw의 전치
    return np.array([[np.cos(theta), -np.sin(theta)],
                     [np.sin(theta),  np.cos(theta)]])

def shear(phi, flip_y=False):                          # 흔들리는 원의 T
    return np.array([[1.0, 1.0 - phi],
                     [0.0, -1.0 if flip_y else 1.0]])  # flip_y=True → 각주3(왼쪽 흔들림)
```

```python
# ── ① 순수 회전 = 직교 행렬 (θ 17표본 전수) ──
for th in np.linspace(0, 2*np.pi, 17):
    T = rot_cw(th)
    assert np.allclose(T.T @ T, np.eye(2))             # TᵀT = I ⇒ 열이 정규직교
    assert abs(np.linalg.det(T) - 1) < 1e-12           # det = cos²+sin² = 1
rng = np.random.default_rng(0)
V = rng.standard_normal((2, 500))                      # 난수 점 500개 (2×N)
assert np.allclose(np.linalg.norm(rot_cw(0.7) @ V, axis=0),
                   np.linalg.norm(V, axis=0))          # ‖Tv‖ = ‖v‖ (TᵀT=I의 귀결)

# ── ③ [그림 6-2] 재현: θ=π/5(36°), x=0 수직선 21점 ──
pts_line = np.vstack((np.zeros(21), np.linspace(-1, 1, 21)))   # 2×N, 각 열 = 한 점
rot_line = rot_cw(np.pi/5) @ pts_line                  # 곱 한 번으로 전 점 회전

# ── ④ 전단은 회전이 아니다 (결정적 대비) ──
S = shear(0.0)                                         # φ=0 → 전단계수 최대
assert abs(np.linalg.det(S) - 1) < 1e-12               # det=1  ← 넓이는 보존
assert not np.allclose(S.T @ S, np.eye(2))             # 그러나 직교가 아니고
assert np.linalg.norm(S @ [0.0, 1.0]) > 1.0            # ⇒ 길이는 미보존
assert np.allclose(shear(1.0), np.eye(2))              # 📌 φ=1이면 T=I
```

```python
# ── 흔들리는 원 (전단 애니메이션 — render()) ──
tt = np.linspace(0, 2*np.pi, 100)
circle = np.vstack((np.sin(tt), np.cos(tt)))           # 원 (2×100)  ※책 순서 (sin, cos)
plth, = ax.plot(circle[0], circle[1], 'ko')            # 핸들 확보(책 원문은 x 미정의 → 점 행렬로 정정)

def aframe(ph):
    P = shear(ph) @ circle
    plth.set_xdata(P[0, :]); plth.set_ydata(P[1, :])   # 재그리지 않고 위치만 갱신(효율)
    return plth,

phi = np.linspace(-1, 1 - 1/40, 40)**2                 # φ: 1 → ≈0 → 0.95 ⇒ 전단계수 1−φ: 0 → ≈1 → 0.05
animation.FuncAnimation(fig, aframe, phi, interval=100, repeat=True)
```
> **관찰 포인트** (실행 결과 — assert 전 블록 통과, 2026-08-04)
> - **직교성 전수 확인** — θ 17표본 전부에서 열 내적 0 · 각 열 노름 1 · $T^{\mathsf{T}}T=I$ · $\det=1$, 난수 벡터 500개에 $\lVert Tv\rVert=\lVert v\rVert$. 컨벤션도 코드로 못 박힘: `rot_cw(θ) = rot_ccw(θ).T = rot_ccw(−θ)`, `rot_cw @ rot_ccw = I`(전치=역), 합성 `R(0.4) @ R(0.9) = R(1.3)`(회전각 덧셈).
> - **[그림 6-2] 재현** — θ=π/5, x=0 수직선 21점. 최상단 $[0,1]^{\mathsf{T}}\mapsto[0.5878,\ 0.8090]^{\mathsf{T}}=[\sin\theta,\ \cos\theta]^{\mathsf{T}}$, 각도 90°→54°로 **정확히 36° 시계**. 점 간격은 등간격 유지, 전 점 노름 보존. `--fig` 산출물을 책 도판과 육안 대조 → 배치·기울기·범위 일치.
> - ⚠️ **전단은 $\det=1$ 이어도 회전이 아니다** 📌 — $S=\begin{bmatrix}1&1\\0&1\end{bmatrix}$($\phi{=}0$)에서 $\det S=1$ 인데 $S^{\mathsf{T}}S=\begin{bmatrix}1&1\\1&2\end{bmatrix}\neq I$ 이고 $\lVert S[0,1]^{\mathsf{T}}\rVert=\sqrt{2}>1$. **넓이는 보존, 길이는 미보존** — 회전(둘 다 보존)과 갈리는 지점이 정확히 여기다.
> - **전단 고유구조** — $S[1,0]^{\mathsf{T}}=[1,0]^{\mathsf{T}}$ 로 x축은 고정(전단의 고유벡터), 고윳값은 $1$ 중근. [[3D 변환 행렬 — 동차좌표·회전·투영 (선형대수 응용)|3D 원자]] 도감의 "전단 고유벡터=x축, 고윳값 1"을 실측으로 회수. `shear(1.0)`은 정확히 $I$.
> - **φ 격자 실측** — `np.linspace(-1, 1-1/40, 40)**2` 는 `phi[0]=1`, 최솟값 $\approx1.64\times10^{-4}$, `phi[-1]=0.9506` 이다. 즉 **격자가 $x=0$ 과 $x=1$ 을 정확히 밟지 않아** φ가 0에 닿지도, 끝에서 1로 완전히 돌아오지도 않는다(전단계수 $1-\phi$: 0 → ≈0.9998 → 0.0494). 끝점을 1에서 $1/40$ 만큼 뗀 것은 루프 재생 시 첫 프레임과 마지막 프레임이 겹치지 않게 하는 장치 — "φ: 1→0→1"이라는 개념 서술은 그대로 유효하고, 격자만 그 양 끝을 아주 살짝 비껴간다.
> - **`plth` = 플롯 핸들(handle)** — 프레임마다 장면을 재생성하지 않고 `set_xdata`/`set_ydata`로 점 위치만 갱신(효율).
> - **책 스니펫 캐비엇의 후속** — p.147 초기 plot `plth, = ax.plot(np.cos(x), np.sin(x), 'ko')` 의 `x` 는 그 스니펫 어디에도 정의돼 있지 않다(정의된 건 `theta` 뿐 → 인쇄본 그대로면 `NameError`). 코드 파일은 이를 점 행렬(`circle`, (sin,cos) 순서)로 통일해 정정했고 **그래서 실행된다.** ⚠️ 다만 옮긴이 GitHub 원본이 `theta`로 돼 있는지는 **미확인** — "책 오타 확정"으로 단정하지 않는다.

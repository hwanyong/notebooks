# 회전·기하 변환 — 순수 회전·직교성·전단

> 📐 **수학 개념원자(SSoT)** — 선형대수. **순수 회전 행렬 = 직교 행렬(길이 보존)** + 행렬-벡터 곱으로 좌표 집합을 변환. 전체 2D/3D 변환 도감(이동·스케일·투영·det 분류·고유벡터)은 [[3D 변환 행렬 — 동차좌표·회전·투영 (선형대수 응용)|3D 변환 행렬 원자]]가 주인 — 이 원자는 **§6.2가 강조하는 순수 회전의 직교성·길이 보존**만 정밀히 담는다.

> 🎯 **핵심 (TL;DR)**
> - **순수 회전 행렬 = 길이를 유지하며 벡터를 회전** 📌 — 아날로그 시계 침(회전하되 길이 불변). 2×N 점 행렬에 왼쪽 곱하면 전 점을 한 번에 회전.
> - **2D 회전 행렬(실전선대):** $T=\begin{bmatrix}\cos\theta & \sin\theta \\ -\sin\theta & \cos\theta\end{bmatrix}$ 📌 — ⚠️ **이건 시계방향(CW)** = 수학 표준 반시계(CCW) 회전행렬의 **전치**. 부호 배치 헷갈리면 각 θ에 점 하나 넣어 검산.
> - **순수 회전 = 직교 행렬** 📌 — 열이 **정규직교**(서로 내적 $\cos\theta\sin\theta-\sin\theta\cos\theta=0$, 각 노름 $\sqrt{\cos^2\theta+\sin^2\theta}=1$). $\det T=\cos^2\theta+\sin^2\theta=1$(넓이·방향 보존). 직교 행렬 **이론 심화는 7장** `(🔭 예고)`.
> - **θ=0 → T=I**(불변), **θ=π/2 → 90° 회전**. 각도를 매개변수로 잡아 **애니메이션** 가능.
> - **흔들리는 원 = 애니메이션된 전단(shear)** 📌 — $T=\begin{bmatrix}1 & 1-\phi \\ 0 & 1\end{bmatrix}$ 는 회전이 아니라 **수평 전단**(대각=1 고정, 비대각 $1-\phi$ 가 기울임). $\det=1$(넓이 보존 — [[3D 변환 행렬 — 동차좌표·회전·투영 (선형대수 응용)|3D 원자]] "전단 det=1"의 실물). $\phi=x^2,\,x\in[-1,1]$ 로 $1{\to}0{\to}1$ → 전단계수 $1-\phi$ 가 $0{\to}1{\to}0$ → 원↔기울어진 타원↔원. $\phi{=}1$이면 $T{=}I$.
> - **CGI·게임 3D 회전 = 4원수(quaternion, $\mathbb{R}^4$)** — 더 복잡하나 "좌표 행렬에 변환 행렬 곱" 원리는 동일 `(🔭 참고)`.

> - 2차원 회전 행렬: $ T=\begin{bmatrix}\cos\theta & \sin\theta \\ -\sin\theta & \cos\theta\end{bmatrix} $
> - **순수 회전 = 직교 행렬**(다음 장에서 더 다룸). $T$ 의 열들은 **직교**(내적 $\cos\theta\sin\theta-\sin\theta\cos\theta=0$)하며 **단위벡터**($\cos^2\theta+\sin^2\theta=1$).
> - 사용: θ=회전각으로 두고 **2×N 기하학적 점 행렬**(각 열=한 점의 (X,Y))에 곱. θ=0 → 위치 불변($T{=}I$). θ=π/2 → 원점 중심 90° 회전.
> - [그림 6-2] θ=π/5(36°) — 수직선 위 점들이 기울어진 직선으로.
>
> **② 가변 회전 애니메이션 — "흔들리는 원(The Wobbly Circle)"**
> - 프레임마다 변환 행렬을 부드럽게 조정. 원 = $(\cos\theta,\sin\theta)$ 점, θ∈[0,2π].
> - 변환 행렬: $ T=\begin{bmatrix}1 & 1-\phi \\ 0 & 1\end{bmatrix} $ — 대각 원소는 x·y축 크기 조정, 비대각은 두 축을 늘림(전단). 값은 저자가 보기 깔끔할 때까지 직접 고름.
> - φ는 $\phi=x^2,\,-1\le x\le1$ 로 $1{\to}0{\to}1$ 전환. **φ=1이면 T=I.**
> - [그림 6-3] 한 프레임(전단된 타원). CGI·게임 3D 그래픽은 **4원수(quaternions)** = 3D 회전·이동시키는 $\mathbb{R}^4$ 벡터라 더 복잡하나, 좌표 행렬에 변환 행렬 곱하는 원리는 동일.

## 🧠 근본 이해 · 융합 · 통찰

### 🔑 순수 회전 = 직교 행렬 = 길이 보존 — 세 표현이 한 사실
- "길이 유지"(시계 침)와 "열이 정규직교"(직교 행렬)와 "$\det=1$"은 같은 사실의 세 얼굴이다. 열이 정규직교면 $T^{\mathsf{T}}T=I$ → 임의 $v$ 에 대해 $\lVert Tv\rVert^2=(Tv)^{\mathsf{T}}(Tv)=v^{\mathsf{T}}T^{\mathsf{T}}Tv=v^{\mathsf{T}}v=\lVert v\rVert^2$ → **노름 불변**. 시계 침의 길이가 안 변하는 이유가 이 한 줄.
- 이 노트가 **직접 보이는 것**은 여기까지(열 정규직교 → 길이 보존). "직교 행렬"이라는 대상의 **일반 이론**(역=전치, 고윳값 크기 1 등)은 책이 명시적으로 **7장으로 미룸** → 규칙17에 따라 정복 대상 아님 `(🔭 7장)`.
- $\det T=1$ 이라 [[3D 변환 행렬 — 동차좌표·회전·투영 (선형대수 응용)|3D 원자]]의 det 분류표 "+1: 회전·전단(넓이·방향 보존)" 행에 정확히 앉는다.

### 🔑 실전선대 T는 시계방향(CW) — 표준 CCW의 전치 (기존 원자와 화해)
- ⚠️ **중대 표기 주의:** 실전선대 $T=\begin{bmatrix}\cos\theta&\sin\theta\\-\sin\theta&\cos\theta\end{bmatrix}$ 는 **시계방향(CW) 회전**이다. 검산: θ=π/2 → $T=\begin{bmatrix}0&1\\-1&0\end{bmatrix}$, $[1,0]^{\mathsf{T}}$ 에 적용 → $[0,-1]^{\mathsf{T}}$(점 (1,0)이 (0,−1)로 = 시계방향 90°).
- 수학 표준(반시계 CCW) 회전행렬은 $\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$ — **부호 배치가 반대**. 두 행렬은 서로 **전치** 관계($R_{CW}=R_{CCW}^{\mathsf{T}}=R_{CCW}^{-1}$, 회전은 직교라 전치=역=반대방향 회전).
- 📌 **[[3D 변환 행렬 — 동차좌표·회전·투영 (선형대수 응용)|3D 원자]]의 $R_z$ 는 표준 CCW** $\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$. **두 노트는 모순이 아니라 방향 컨벤션 차이(전치 관계)** — 실전선대는 CW, 3D 원자·수학 표준은 CCW. 회전각 부호나 sin 위치만 다름. 책 각주2가 "사인들의 빼기 기호를 맞바꾸면 반대 방향(CCW)"이라 한 것이 이 전치.

### 🔑 흔들리는 원 = 애니메이션된 전단 (3D 원자 "전단 det=1" 회수)
- 책 도입은 "가변 회전"이라 느슨히 부르지만, $T=\begin{bmatrix}1&1-\phi\\0&1\end{bmatrix}$ 는 **회전이 아니라 수평 전단(shear)** — 대각이 1로 고정이라 크기(스케일)는 안 변하고, 비대각 $1-\phi$ 가 y에 비례해 x를 밀어 기울인다. 원에 전단을 걸면 **기울어진 타원**([그림 6-3]).
- $\det=1\cdot1-(1-\phi)\cdot0=1$ — **넓이 보존.** [[3D 변환 행렬 — 동차좌표·회전·투영 (선형대수 응용)|3D 원자]] "2D 아핀 총람"의 "전단 x/y det=1(기울어져도 밑변×높이 유지)"가 여기 애니메이션으로 살아 움직이는 것. 전단의 고유벡터도 그 도감에 있음(x축 $[1,0]$, 고윳값 1) → 전 변환 도감·det·고유벡터는 3D 원자에 위임.
- 흔들림의 정체 = 전단계수 $1-\phi$ 가 $0{\to}1{\to}0$($\phi:1{\to}0{\to}1$). $\phi=1$(=$x=\pm1$)에서 $1-\phi=0$ → $T=I$ → 원. $\phi=0$(=$x=0$)에서 $1-\phi=1$ → 최대 전단. **크기는 절대 안 변하고(det=1) 기울기만 오가는** 게 "흔들림".

### 🔑 변환 = 행렬 @ 점 행렬 (2.2 회수, 원점 기준)
- [[2.2 행렬 곱셈·행렬식|2.2]]에서 "행렬 = 변환, 행렬곱 = 변환 합성"을 봤다 — 여기선 그 변환을 **2×N 점 행렬 전체에 한 번에** 적용($P=T@\text{points}$): 각 열이 한 점이라 곱 한 번으로 모든 점이 변환된다(for문 불필요).
- 이 회전·전단은 전부 **원점 기준(about origin)**. 임의 점 기준 회전은 [[3D 변환 행렬 — 동차좌표·회전·투영 (선형대수 응용)|3D 원자]]의 $T_p R T_{-p}$ 합성(이동∘회전∘역이동)이 필요 — 동차좌표로 3×3 한 방에 접힘. 여기(§6.2)는 원점 기준 순수 회전·전단만.

## 🧩 코드 (§6.2)
> 🎯 목표: 변환 행렬 $T$ 를 2×N 점 행렬에 곱해 회전/전단 + `FuncAnimation`으로 애니메이션(핸들 갱신).
> 코드: `~/LOCAL/03-00_STUDIES/AI/01_linear_algebra/la6_geometry.py` (예정)

```python
import numpy as np
import matplotlib.pyplot as plt
from matplotlib import animation

# ── 순수 회전 (θ 고정) ──
theta = np.pi/5                                   # 36°, CW 컨벤션(실전선대)
T = np.array([[ np.cos(theta),  np.sin(theta)],
              [-np.sin(theta),  np.cos(theta)]])   # ⚠️ CW = 표준 CCW의 전치
pts = np.vstack((np.zeros(20), np.linspace(-1,1,20)))  # 수직선 위 점들 (2×N)
rot = T @ pts                                      # 한 번의 곱으로 전 점 회전
```

```python
# ── 흔들리는 원 (전단 애니메이션) ──
theta = np.linspace(0, 2*np.pi, 100)
points = np.vstack((np.sin(theta), np.cos(theta)))   # 원 (2×100)  ※책: (sin,cos) 순서

fig, ax = plt.subplots(1, figsize=(12,6))
plth, = ax.plot(points[0,:], points[1,:], 'ko')      # 핸들 확보(책 원문은 x 미정의 — theta로 정정)

def aframe(ph):
    T = np.array([[1, 1-ph], [0, 1]])                # 전단 행렬 (det=1)
    P = T @ points
    plth.set_xdata(P[0,:]); plth.set_ydata(P[1,:])   # 재그리지 않고 위치만 갱신(효율)
    return plth

phi = np.linspace(-1, 1-1/40, 40)**2                 # φ: 1→0→1  ⇒ 전단계수 1−φ: 0→1→0
animation.FuncAnimation(fig, aframe, phi, interval=100, repeat=True)
```
> 관찰 포인트: `plth` = 플롯 핸들(handle) — 프레임마다 장면 재생성 없이 `set_xdata/ydata`로 점만 이동(효율). `det(T)=1`이라 넓이 불변. 책 스니펫 캐비엇: 초기 plot이 `np.cos(x),np.sin(x)`로 `x` 미정의 + (cos,sin) 순서였음 → 여기선 `points`(sin,cos)로 통일해 정정.

| **CW vs CCW 컨벤션** | 실전선대 T=시계방향(CW)=표준 반시계(CCW) 회전행렬의 전치; sin 부호 위치가 반대 |
| **전단** (shear) | 대각 고정·비대각이 한 축을 밀어 기울임; $\begin{bmatrix}1&1-\phi\\0&1\end{bmatrix}$; det=1(넓이 보존) |
| **흔들리는 원** (wobbly circle) | 전단계수를 $0{\to}1{\to}0$ 애니메이션 → 원↔기울어진 타원; 크기 불변 |
| **4원수** (quaternion) | 3D 회전·이동을 다루는 $\mathbb{R}^4$ 벡터(CGI·게임); 범위 밖 |
